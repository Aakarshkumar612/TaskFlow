🏗️ Core System Components

Client Layer

React SPA with Vite, served via Nginx. Handles routing, state management, and API communication with automatic token attachment.

API Gateway

Express.js server with middleware pipeline: CORS, Helmet, compression, logging, authentication, and error handling.

Auth Layer

Clerk integration with JWT verification, auto-provisioning middleware that syncs Clerk users to PostgreSQL on first login.

Data Layer

PostgreSQL with Prisma ORM. Type-safe queries, migrations, and relationship management across 7 interconnected tables.

Real-time Layer

WebSocket service for live updates on task changes, notifications, and team collaboration events.

Containerization

Docker Compose orchestrates 3 services: PostgreSQL, Backend API, and Frontend with Nginx, with health checks and volume persistence.

🔄 Request Flow

1

User Authentication

Browser → Clerk → JWT Token → Stored in session

2

API Request

Frontend attaches Bearer token → Sends to Express API

3

Middleware Processing

CORS → Helmet → Auth Verification → User Provisioning

4

Database Query

Prisma ORM executes type-safe SQL → PostgreSQL returns data

5

Response & Real-time

JSON response sent → WebSocket broadcasts update to connected clients

🔐 Authentication Flow

1

User Signs Up/Logs In

Clerk handles authentication → Returns JWT session token

2

Token Storage

Token stored in browser session → Available via Clerk's getToken()

3

API Request with Auth

Axios interceptor attaches Bearer token to every request header

4

Backend Verification

Auth middleware verifies JWT → Extracts user ID → Checks/creates user in PostgreSQL

5

Auto-Provisioning

If user doesn't exist in DB → Creates User record from Clerk data → Proceeds with request

Deployment

Docker & Deployment Architecture

Containerized deployment strategy with multi-stage builds, health checks, and service orchestration using Docker Compose.

🐳 Docker Services

PostgreSQL (postgres:16-alpine)

Lightweight Alpine-based database. Persistent volume for data. Health check with pg_isready. Port 5432 exposed for external tools.

Backend (node:20-slim)

Multi-stage build: deps → build → runner. Non-root user for security. Prisma auto-generated. Health check on /health endpoint. Port 5000.

Frontend (nginx:1.25-alpine)

React built with Vite → Served by Nginx. SPA routing configured. Gzip compression enabled. Security headers. Port 3000 → 80.

🚀 Deployment Commands

# Start all services
docker compose up -d
# View logs
docker compose logs -f
# Run database migrations
docker compose exec backend npx prisma db push
# Stop services
docker compose down
